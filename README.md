# kiosk-app-sample

業務用キオスク端末アプリのサンプルコードです。

実案件のソースコードは非公開のため、実績紹介用に、キオスク型アプリの基本動作を小さく再現したサンプルを公開しています。

## 実案件について

2023〜2024年に、業務用Android端末（POSレジ・業務用スマートフォン）向けのキオスク型アプリを Python で開発しました。端末のUIや表示できるページを制限し、業務に必要な画面だけを使えるようにするアプリです。単発の開発案件として納品し、その後もアップデート等のスポット対応を行っています。

## このサンプルの内容

PC上で動くデモ版として、同じ考え方を Tkinter で再実装したものです。

- 全画面・最前面で起動し、許可されたページ（`ALLOWED_PAGES`）だけを表示
- 一定時間（初期設定60秒）操作がないとホーム画面へ自動復帰
- 終了は管理者PINを入力したときだけ可能（Alt+F4 やウィンドウの×で閉じようとした場合も同じ）
- PINを3回続けて間違えると30秒間ロック

### アプリで制限する範囲について

アプリ側で制限できるのは、アプリ内の操作までです。Alt+Tab やOSのショートカットなど、OS側の操作による切り替えは、実機ではOSのキオスク機能（Android の画面固定・専用端末モード、Windows の割り当てられたアクセスなど）と組み合わせて制限します。実案件でも、端末側の設定とアプリをセットで運用しています。

## 実行方法

```bash
python3 kiosk_app.py
```

- 使用技術：Python 3.11 以上 / Tkinter（標準ライブラリのみ、追加インストール不要）
- 管理者PINの初期値は `1234`。環境変数 `KIOSK_EXIT_PIN` で変更できます

```bash
KIOSK_EXIT_PIN=9876 python3 kiosk_app.py
```

## テスト

```bash
python3 -m unittest -v
```

PINの照合とロック、許可ページ以外を表示しないこと、無操作でのホーム復帰、ウィンドウを閉じる操作にもPINが必要なことなどを確認する12本のテストがあります。画面を使うテストは、ディスプレイのない環境では自動でスキップされます。
